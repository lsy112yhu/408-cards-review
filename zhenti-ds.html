ds-1 · 算法时空复杂度 · 量级判定与递归式求解
真题实战 · 2025 年第 1 题（选择题）
下列程序段的时间复杂度是（　）。
int count=0, i, j; for(i=1; i*i<=n; i++) for(j=1; j<=i; j++) count ++;
A. O(log n)　　B. O(n)　　C. O(n log n)　　D. O(n²)
解析 · 答案：B
数 count 的总执行次数。外层 i 从 1 到 i*i ≤ n，即 i ≤ √n；内层对每个 i 执行 i 次。总次数 = 1 + 2 + … + √n = √n(√n + 1)/2 ≈ n/2，量级 Θ(n) → B。
A 只看见外层 √n 的影子（且误成 log），漏了内层随 i 线性增长这一项；C、D 则高估。自查：已用程序按 n = 10⁴、10⁶ 实测 count = 5050、500500，稳定在 0.5n 附近 ✓。
ds-2 · 顺序表与链表对比 · 存取与增删复杂度
真题实战 · 2024 年第 1 题（选择题）
已知带头结点的非空单链表 L 的头指针为 h，结点结构为 data | next，其中 next 是指向直接后继结点的指针。现有指针 p 和 q，若 p 指向 L 中非首且非尾的任意一个结点，则执行语句序列「q=p->next; p->next=q->next; q->next=h->next; h->next=q;」的结果是（　）。
A. 在 p 所指结点后插入 q 所指结点　　B. 在 q 所指结点后插入 p 所指结点
C. 将 p 所指结点移动到 L 的头结点之后　　D. 将 q 所指结点移动到 L 的头结点之后
解析 · 答案：D
四句逐步追踪指针。① q = p->next：q 先抓住 p 的后继结点。② p->next = q->next：p 跳过 q、直连 q 的后继——q 已从链上被摘下（这一步是删除，不是插入）。③ q->next = h->next：让 q 的后继指向原来的首元结点。④ h->next = q：头结点改指 q。合起来：把 q 所指结点从原位置摘下、移到头结点之后 → D。
C 移动的对象说错了：全程 p 本人纹丝不动，动的只有 p 的 next 指针；被摘下又被安到表头的始终是 q。这正是链表增删的看家本领——只改指针、不搬数据，与顺序表靠移动元素形成对照。自查：执行完后链上结点一个不多一个不少，只是 q 的位置变了。
ds-3 · 栈与队列经典应用
真题实战 · 2025 年第 2 题（选择题）
已知算法 A 用于检查字符串中各类括号是否匹配，A 执行过程中使用初始为空的栈保存遇到的括号。若栈的容量是 3，则下列选项中，A 不能处理的是（　）。
A. (a + [b + (c + d) / e] + f) + g – h
B. [a * ((b + c) / (d – e) + f / g) - h]
C. [a * (b – (c – d) * e / (f + g)) – h]
D. [a – (b + [c * (d + e) – f] + g + h)]
解析 · 答案：D
四个表达式的括号本身都匹配，卡点只在嵌套深度——栈里同时保存的左括号个数。逐式数最大深度：A 中 ( → [ → (，深度 3，恰好够用；B 中 [ → ( → (，深度 3；C 中 [ → ( → (，其后 (f + g) 的左括号是在 (c – d) 已弹出后才入栈，最大深度仍是 3；D 中 [ → ( → [ → (，深度达到 4，超过容量 3，第三个左括号之后再入栈即溢出 → A 不能处理 → D。
自查：已用程序逐式模拟括号栈，A、B、C 最大深度均为 3、D 为 4 ✓。
ds-4 · 循环队列 · 判空判满与元素个数
真题实战 · 2014 年第 3 题（选择题）
循环队列放在一维数组 A[0..M-1] 中，end1 指向队头元素，end2 指向队尾元素的后一个位置。假设队列两端均可进行入队和出队操作，队列中最多能容纳 M-1 个元素。初始时为空。下列判断队空和队满的条件中，正确的是（　）。
A. 队空：end1 == end2；队满：end1 == (end2 + 1) mod M
B. 队空：end1 == end2；队满：end2 == (end1 + 1) mod (M - 1)
C. 队空：end1 == (end1 + 1) mod M；队满：end1 == (end2 + 1) mod M
D. 队空：end1 == (end2 + 1) mod M；队满：end2 == (end1 + 1) mod (M - 1)
解析 · 答案：A
先定队空：初始为空且两指针同位，队列排空时必然回到 end1 == end2。C 的队空式 end1 == (end1 + 1) mod M 恒不成立，D 把队满的式子安给了队空，先排 C、D。
再定队满：end2 指在队尾的后一格，队列最多容 M − 1 个元素——专门空出一格，就是为了让队满状态区别于队空。队满时 end2 再前进一格恰好撞上 end1，即 end1 == (end2 + 1) mod M → A。B 把模数错写成 M − 1、且主客颠倒。自查：与本卡判空判满通式一致——空满同用一对指针，靠「满时差一位」把两种状态分开。
ds-5 · 特殊矩阵与稀疏矩阵的压缩存储
真题实战 · 2018 年第 3 题（选择题）
设有一个 12 × 12 的对称矩阵 M，将其上三角部分的元素 mi,j（1 ≤ i ≤ j ≤ 12）按行优先存入 C 语言的一维数组 N 中，元素 m6,6 在 N 中的下标是（　）。
A. 50　　B. 51　　C. 55　　D. 66
解析 · 答案：A
上三角按行优先，第 i 行存 i ≤ j 的元素共 12 − i + 1 个。m6,6 排在第 6 行的第一个（该行从 j = i = 6 开始），它前面是完整的第 1~5 行：12 + 11 + 10 + 9 + 8 = 50 个元素。C 数组下标从 0 起，前面有 50 个元素，它自己的下标就是 50 → A。
B 的 51 是把下标按 1 起算、或把自己也数了进去；C 的 55 是误把每行都按 11 个算；D 的 66 是拿整行 12 去乘的行差。自查：已用程序求和复核 50 ✓。
ds-6 · KMP 串模式匹配 · next 数组与 nextval
真题实战 · 2024 年第 6 题（选择题）
KMP 算法使用修正后的 next 数组进行模式匹配，模式串 S =「aabaab」，当主串中某字符与 S 中某字符失去配对时，S 将向右滑动的最长距离是（　）。
A. 5　　B. 4　　C. 3　　D. 2
解析 · 答案：A
「修正后的 next 数组」即 nextval。先算 next（下标 j = 0…5）：(−1, 0, 1, 0, 1, 2)；再修正——若 S[j] 与 S[next[j]] 相同则继续回退，得 nextval = (−1, −1, 1, −1, −1, 1)。
在位置 j 失配时，模式串向右滑动距离 = j − nextval[j]，逐 j 算：j=0 时 1，j=1 时 2，j=2 时 1，j=3 时 4，j=4 时 5，j=5 时 4。最长出现在 j = 4 处失配：滑 5 格 → A。关键在「修正」二字：j = 1、3、4 处失配字符与原回退位置的字符同为 'a'，用未修正的 next 只会白比一遍，nextval 把这一步提前跳过，滑动距离随之放大。自查：已用程序按定义求 next/nextval 并逐 j 计算滑动距离，最大为 5 ✓。
ds-7 · 二叉树性质公式
真题实战 · 2011 年第 4 题（选择题）
若一棵完全二叉树有 768 个结点，则该二叉树中叶结点的个数是（　）。
A. 257　　B. 258　　C. 384　　D. 385
解析 · 答案：C
两条性质联用：二叉树恒有 n0 = n2 + 1；完全二叉树中度为 1 的结点至多 1 个。n = 768 为偶数时，n1 必为 1（若 n1 = 0 则 n = n0 + n2 = 2n0 − 1 为奇数，矛盾）。代入 n0 + n1 + n2 = 768 且 n2 = n0 − 1：2n0 = 768，n0 = 384 → C。
换个角度按编号验：编号大于 768/2 = 384 的结点（385…768）都没有孩子、都是叶，共 384 个。D 的 385 是 n 为奇数时 (n + 1)/2 的公式串了台；A、B 是把层数算错的量级。自查：384 = 768/2，与偶数情形 n0 = n/2 吻合 ✓。
ds-8 · 完全二叉树编号规律
真题实战 · 2025 年第 3 题（选择题）
若二叉树的结点值均为正整数，采用顺序存储方式保存在数组 R 中，用 −1 表示结点不存在，则下列数组中，不能表示一棵二叉树的是（　）。
A. R[] = {20, 15, 40, −1, −1, 35}
B. R[] = {15, 40, 10, 18, 35, −1, −1}
C. R[] = {15, 40, 10, −1, −1, −1, 12}
D. R[] = {17, 20, 35, −1, 18, 45, −1, −1, 19, 27}
解析 · 答案：D
顺序存储的编号铁律：下标 i（从 1 起）处有结点，则其双亲 ⌊i/2⌋ 处必须也有结点，否则这个结点是无父的「孤儿」。逐项只查孤儿：A 中 35 在 6 号位，双亲 3 号位是 40，在 ✓；B 中 18、35 在 4、5 号位，双亲 2 号位是 40，在 ✓；C 中 12 在 7 号位，双亲 3 号位是 10，在 ✓；D 中 19、27 在 9、10 号位，双亲应为 4 号位，而 4 号位是 −1——父不存在、子却存在，不可能是一棵二叉树 → D。
自查：已用程序按同一判据逐项验证，仅 D 出现孤儿结点 ✓。注意 A 的 35 虽然其「兄弟位」5 号是空的也完全合法——编号规律只要求父链不断，不要求兄弟齐全。
ds-9 · 树、森林与二叉树的转换
真题实战 · 2026 年第 4 题（选择题）
已知由 5 棵树组成的森林 F 中各棵树所含的结点个数分别是 2, 3, 4, 5, 7。若 F 中各棵树的排列次序任意，则与 F 对应的二叉树的高度至少是（　）。
A. 5　　B. 6　　C. 8　　D. 10
解析 · 答案：B
先看转换后的骨架：森林各树的根在二叉树里串成一条右链，第 k 棵树（从 1 计）的根位于深度 k，它的内部结构挂在这条根的左下方。所以总高度 = max((k − 1) + hk)，其中 hk 是第 k 棵树单独转换后的高度。
再算每棵树能压到的最小 h（树形也任选，把孩子尽量横向摊开、缩短孩子-兄弟链）：结点数 2、3、4、5、7 的树，h 至少依次为 2、3、3、4、4。最后排次序：h 大的树排前面（深度偏移小），取 h 序列 4, 4, 3, 3, 2，各位置贡献 0+4、1+4、2+3、3+3、4+2 = 4、5、5、6、6，最大 6 → B。A 的 5 只差一层，是把最后一棵树的根深度漏算了一层。自查：已用程序枚举全部树形与排列次序，最小高度恰为 6 ✓。
ds-10 · 二叉树：由遍历序列定树
真题实战 · 2026 年第 3 题（选择题）
若二叉树 T 的中序遍历序列是 b, e, d, f, c, a, g，层序遍历序列是 a, b, g, c, d, e, f，则 T 的后序遍历序列是（　）。
A. c, e, d, f, b, g, a　　B. c, e, f, d, b, g, a
C. e, f, d, c, b, g, a　　D. e, g, f, d, b, c, a
解析 · 答案：C
层序给「谁先当根」，中序给「左右怎么分」，逐层重建。层序首元 a 是整树根；中序里 a 左侧 b, e, d, f, c 归左子树、右侧 g 归右子树，g 即根的右孩子。
左子树内看层序的相对次序 b, c, d, e, f：b 最先，b 是左子树根；中序中 b 左侧为空——b 没有左孩子，右侧 e, d, f, c 是 b 的右子树。再往下：c 在层序中先于 d、e、f，c 是这棵右子树的根，其左子树为 e, d, f、右子树空；d 再作根，左 e 右 f。树形至此唯一确定。后序 = 左子树后序 (e, f, d, c, b) ＋ 右孩子 g ＋ 根 a = e, f, d, c, b, g, a → C。A、B 错在把 c、b 两层的出场顺序排反（后序必须先走完最深的左下角）。自查：已用程序按中序＋层序重建并输出后序，与 C 逐字一致 ✓。
ds-11 · 线索二叉树 · 线索化与找前驱 / 后继
真题实战 · 2013 年第 5 题（选择题）
若 X 是后序线索二叉树中的叶结点，且 X 存在左兄弟结点 Y。则 X 的右线索指的是（　）。
A. X 的父结点　　B. 以 Y 为根的子树的最左下结点
C. X 的左兄弟结点 Y　　D. 以 Y 为根的子树的最右下结点
解析 · 答案：A
叶结点没有右孩子，它的右指针就是线索，指向后序序列中的后继。把后序次序排出来看：父结点的出场顺序是「左子树（即 Y 的整棵子树）→ 右子树（X 是其中一员，本题 X 为叶）→ 父结点本人」。X 排在其父的右子树里、且 X 之后紧接着的就是父结点（右子树访问完，立刻回到父）。
故 X 的后序后继正是它的父结点，右线索指向父结点 → A。B、C、D 都落在 Y 的子树内部或 Y 本人身上——那些结点在后序中全部排在 X 之前，是前驱一侧，与右线索（指后继）方向正好相反。自查：后序线索化中，叶结点的右线索恒指后继；本题后继恰落在父结点上，与「有左兄弟」这一条件互证。
ds-12 · 哈夫曼树（最优二叉树）
真题实战 · 2026 年第 5 题（选择题）
已知二叉树 T 中 7 个叶结点 a, b, c, d, e, f, g 的权值分别是 1, 2, 4, 5, 8, 10, 12，当 T 的带权路径长度最小时，与结点 e 深度相同的叶结点仅有（　）。
A. d　　B. g　　C. d、f　　D. f、g
解析 · 答案：D
按哈夫曼规则逐步合并（每次取最小的两个）：1 + 2 = 3；3 + 4 = 7；5 + 7 = 12；8 + 10 = 18；12 + 12 = 24；18 + 24 = 42。
定位 e（权 8）：它直到第 4 步才与 10 合并成 18，而 18 是根的直接孩子（根 42 = 18 + 24），故 e 的深度为 2。同一深度 2 的叶还有：f（权 10，与 e 同属 18 号内结点）与 g（权 12，位于 24 之下，深度同为 2）。d（权 5）则在第 3 步先与 7 合并，深度为 3，不算。故与 e 同深度的仅 f、g → D。C 多带了 d，是合并次序没走完就凭权值相近猜的。自查：已用程序穷举合并时平局的全部变体，最小 WPL 恒为 106、e 的深度恒为 2、同深度叶恒为 {f, g} ✓。
ds-13 · 图的存储对比
真题实战 · 2026 年第 6 题（选择题）
若用邻接表保存有向图 G=(V, E)，则计算 G 中某顶点入度的时间复杂度是（　）。
A. O(|V|)　　B. O(min(|V|, |E|))　　C. O(|E|)　　D. O(max(|V|, |E|))
解析 · 答案：D
邻接表里每个表头挂的是该顶点的出边。求某个顶点 v 的入度，没有现成字段可读，只能把所有顶点的边表从头扫到尾、逐条统计终点为 v 的边：边表总量 |E| 条，这是 O(|E|) 的部分；同时要逐个走过全部 |V| 个表头结点才能把每条边表都访问到，这是 O(|V|) 的部分。合计 Θ(|V| + |E|)，与 O(max(|V|, |E|)) 同阶 → D。
C 只写 O(|E|) 漏了扫表头的 |V|：当图稀疏到 |E| < |V| 时，这个漏项就是主项。A、B 量级都不够。自查：这正是邻接表的招牌不对称性——出度读本点边表即可，入度必须全表扫描；与本卡「图的存储对比」里邻接表一栏互证。
ds-14 · 图的遍历与生成树
真题实战 · 2015 年第 5 题（选择题）
设有向图 G=(V,E)，顶点集 V={ v0, v1, v2, v3 }，边集 E={ <v0,v1>, <v0,v2>, <v0,v3>, <v1,v3> }。若从顶点 v0 开始对图进行深度优先遍历，则可能得到的不同遍历序列个数是（　）。
A. 2　　B. 3　　C. 4　　D. 5
解析 · 答案：D
DFS 的不确定性只来自邻接点的取舍次序，本图中只有 v0 有三条出边需要排列（v1 仅一条出边指向 v3）。按 v0 第一条走的边分类枚举：先走 v1：深入 v1 再到 v3，回溯到 v0 后只剩 v2，得 v0 v1 v3 v2（1 条）；先走 v2：v2 是死胡同，回溯后 v1、v3 的走法有两种，得 v0 v2 v1 v3 与 v0 v2 v3 v1（2 条）；先走 v3：回溯后 v1、v2 的先后有两种，得 v0 v3 v1 v2 与 v0 v3 v2 v1（2 条）。合计 5 条 → D。
漏数的常见原因是只按「第一条边」分类而丢了回溯后的分支。自查：已用程序固定邻接次序枚举全部排列并模拟标准 DFS，去重后恰为这 5 条 ✓。
ds-15 · 最小生成树对比 · Prim vs Kruskal
真题实战 · 2012 年第 8 题（选择题）
下列关于最小生成树的叙述中，正确的是（　）。
I. 最小生成树的代价唯一
II. 所有权值最小的边一定会出现在所有的最小生成树中
III. 使用普里姆（Prim）算法从不同顶点开始得到的最小生成树一定相同
IV. 使用普里姆算法和克鲁斯卡尔（Kruskal）算法得到的最小生成树总不相同
A. 仅 I　　B. 仅 II　　C. 仅 I、III　　D. 仅 II、IV
解析 · 答案：A
I 正确：最小生成树的形状可以不唯一，但其总权值（代价）由图唯一决定——任何一棵 MST 的权值和都等于那个最小值。
II 错误：「所有权值最小的边」若有多条并列（权值相同），其中某一条完全可能被另一条并列边顶替而不出现在某一棵 MST 中；只有当最小边唯一时它才必入每棵 MST，「一定会出现在所有」说绝了。III 错误：Prim 从不同顶点起步，遇到并列权边时取舍路径不同，可以得到形状不同的 MST（代价相同）。IV 错误：「总不相同」同样过绝——当图的边权互异时 MST 唯一，两种算法必然得到同一棵树。仅 I → A。自查：本卡对比的总开关就是一句「代价唯一、树形不唯一」，II、III、IV 都死在把「不唯一」或「唯一」说反了方向。

真题实战 · 2023 年第 6 题（选择题）

I. 普里姆（Prim）算法
II. 克鲁斯卡尔（Kruskal）算法
III. 图的广度优先搜索算法
A. 仅 I　　B. 仅 III　　C. 仅 I、II　　D. I、II、III
解析 · 答案：B（注：2023 年答案键为第三方「研芝士」版）
I、II 是最小生成树算法，求的是「连通全部顶点的最小总权树」。Prim 维护的距离是各点到已生成树的最小边权，不是到源点的最短路径长；生成树上的路径更不保证最短。故 I、II 都不能保证求出最短路径。

ds-17 · 拓扑排序（AOV 网：顶点活动网）
真题实战 · 2016 年第 7 题（选择题）

A. O(n)　　B. O(n + e)　　C. O(n²)　　D. O(n · e)
解析 · 答案：B
把拓扑排序的工作拆开计。准备阶段：为每个顶点算入度，要扫一遍邻接表的全部边，O(e)，外加遍历 n 个表头，O(n)。主循环：每个顶点恰出栈（输出）一次，每条弧恰被处理一次（使其终点入度减 1），合计 O(n + e)。总代价 O(n + e) → B。
C 的 O(n²) 是邻接矩阵存储下的量级：每找一个入度为零的顶点要扫一整行、重复 n 次。本题明说邻接表，不要把两种存储的账算混。自查：与 ds-13 同源——邻接表下一切「扫全部边一次」的算法都是 O(n + e) 这一档。
